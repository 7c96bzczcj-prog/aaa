Gene Expression

These files contain RNA expression data for each cell type reported as transcripts per million (TPM). Each row contains the expression value for the gene indicated in column A, and starting in column D are individual replicates from different donors. Replicates from the same donor are not necessarily in the same column.

DICE eQTLs

These files contain eQTL data in VCF format, which list genetic polymorphisms that have a significant association with the expression of a nearby gene. The following thresholds were applied: Adj. P value < 0.05, raw P value < 0.0001 and TPM > 1.0. If the expression of more than one gene is associated with a given SNP, there will be an entry (row) for each polymorphism:gene combination (multiple rows per SNP).
