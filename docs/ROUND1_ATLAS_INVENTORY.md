# NK 公开图谱二次分析 — 第一轮：清点报告

对应《第一轮任务说明 v1.0》。本轮只做清点：读取的只有元数据（obs、var、uns 的键），没有读取任何表达值，没有计算签名评分或差异表达，也没有重跑整合或聚类。

## 结论

**血源样本量不支持把外周血设为主分析隔室。**

- 图谱 A 的病人外周血：164 份样本，126 例病人，11 个瘤种，65,766 个 NK。病人数 ≥ 20 的瘤种只有 HNSCC（41 例）和 BRCA（23 例）。
- 图谱 B 的所有 NK 对象里都没有病人外周血，外周血只有 12 名健康供者。因此两套图谱无法在血液隔室里对照。
- **瘤内隔室的对应样本量：**
  - 图谱 A：772 份样本，593 例病人（按数据集限定键计；原始病人 ID 为 557 个），24 个瘤种，34,900 个 NK，每样本 NK 中位数 22（IQR 8.8–43）。
  - 图谱 B：38,982 个 NK，428 例病人（原始病人 ID 423 个），7 个瘤种。

判据和敏感性分析见第 4 节。

## 4. 结论的判据

任务说明写明主隔室"交给样本量去定"，但没有给数值门槛。我用下面三条描述性标准，结论在任何合理的门槛下都不变。

1. **两套图谱是否都有该隔室**
   - 外周血：只有图谱 A 有，图谱 B 为 0。两套图谱的分歧只能在瘤内隔室里检视。
   - 瘤内：两套都有，且有 5 个共有瘤种。
2. **每瘤种病人数**（以 ≥ 20 例作为参考尺度）
   - 外周血：11 个瘤种里只有 2 个达到。有 6 个瘤种少于 10 例，其中 ICC 只有 1 例。
   - 瘤内（图谱 A）：11 个瘤种达到。
3. **瘤种与数据集是否混杂**
   - 外周血的 11 个瘤种中有 8 个只来自单一数据集，瘤种效应与数据集效应无法分开。
   - 最大的血源瘤种 BRCA 共 26,660 个 NK，其中 25,860 个（97%，21/23 例病人，48/57 份样本）来自同一套治疗试验数据 GSE169246；其余 800 个来自 GSE114725（2 例）。对象没有时点字段，无法筛出治疗前血样。

反方向的一点：外周血每样本 NK 数更多（中位数 184，瘤内是 22）。这一点影响的是每个样本内的精度，不改变病人数和瘤种覆盖上的差距。

## 5. 未解决、留待 PI 决定的事项

- **A 的 160,011 个 NK 无法由存档对象直接复现。** A_main 为 142,304；A_blood 中不在 A_main 里的样本另有 63 份。两对象 cellID 格式不同，不能直接取并集。另有两个未下载的对象 `Integrated_CD56/CD16_NK cells`，约 4.2 GB。
- **A 的健康供者数**：原文 35 名，对象中为 70 个 ID。
- **"批次"字段的语义**：图谱 A 的 `batch` 实为"病人-数据集"组合，不是技术批次。
- 上述转移、随访、时点、年龄、性别字段在存档对象中均缺失；它们能否从补充材料补齐，见独立核查的结果。
