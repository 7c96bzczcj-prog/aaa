## §0 这项任务的定位

议题二拟从机械感受的角度提出 NK 的新问题。在提出任何方向之前，须先确认最基本的事实：**NK 是否表达 PIEZO1、表达到什么程度、在何处有差异。**

若 PIEZO1 在 NK 中落入不可测区间，则一切基于转录本的比较均不成立，后续方向须改用蛋白或功能读数——**这一判定必须先于方向讨论完成**。

**本任务只出事实，不作方向判断，不提机制假说。**

### 一条必须写在开头的限制

PIEZO1 是机械敏感离子通道，其活性取决于膜张力与局部力学环境，**不仅取决于表达量**。同样的转录本水平，在不同环境下的通道活性可以相差很大。

**因此本任务给出的是「表达底数」，不是「机械感受能力」。** 该限制须置于每份输出文件的开头。

## §2 七个问题

### Q1｜NK 是否表达 PIEZO1，表达到什么程度

在三个数据集中分别计算 NK 细胞的 `PIEZO1` **检出率**与**平均表达量**，按供者层级汇总（中位数与四分位距）。

**同时报告可测性带**：< 5% 地板 / 5–85% 可测 / > 85% 天花板。

**这一项是全部后续问题的前提。** 若 PIEZO1 在多数数据集中落地板带，须在输出的开头明确写出，并标注后续各问的结论均受此限制。

### Q2｜与其他机械敏感通道相比，PIEZO1 是否确为主要者

Yanamandra 等（Eur J Immunol 2024）称 PIEZO1 为 NK 中主要表达的机械敏感通道。**该论断须自行验证，不得直接引用。**

在同一批 NK 细胞中并列计算下列基因的检出率与平均表达量：

`PIEZO1`、`PIEZO2`、`TRPV4`、`TRPV2`、`TRPM7`、`TRPC1`、`TMEM63A`、`TMEM63B`、`KCNK2`（TREK-1）、`KCNK4`（TRAAK）

**判读**：若 PIEZO1 并非其中最高者，须如实报告——这将直接影响议题二的对象选择。

### Q3｜不同器官来源的 NK 之间是否有差异

在跨组织图谱中，逐器官计算 NK 的 `PIEZO1` 检出率，输出格式与议题一的募集因子对照表一致，**便于并排比较**。

沿用议题一确立的全部规则：统计单元为供者；不跨化学版本并列排序；供者数 < 3 或该器官 NK 细胞数 < 200 记 `INSUFFICIENT`。

### Q4｜肿瘤中的 NK 是否有差异

**两个层面分别做，不可混为一谈：**

- **人（`GSE154826`）**：同一患者的肿瘤 NK 与癌旁肺 NK 配对比较，19 对，配对 t 检验。
- **小鼠（`E-MTAB-10176`）**：新浸润（绿）与滞留（红）NK 的比较，并按议题一的二项稀释零模型计算残差与排名百分位。

**后者尤其重要**：若 `Piezo1` 在进入组织后显著变化，则它落在「进入组织」这一事件的时间窗内。请一并报告其残差百分位，与议题一的驻留程序基因（`Klf2`、`S1pr1`、`Itga1`、`Cd69`、`Itgam`、`Cxcr4`）并列呈现。

### Q5｜CD56^bright 与 CD56^dim 之间是否有差异

**这一项须谨慎处理。** 议题一已确认：转录本层面的 NK 亚群分层不可靠——作者标签存在循环论证，按 `FCGR3A`＋`NCAM1` 重画则自相矛盾（25.5% 细胞无法归类，严格与宽松两套阈值给出方向相反的结果）。

因此本项的做法是：

- 用两套标签（作者注释、`FCGR3A`＋`NCAM1` 重画）**分别**计算，并列呈现；
- 若两套结果方向不一致，记 `UNRELIABLE`，**不得择一采用**；
- 无论结果如何，均须标注「亚群分层在转录本层面不可靠」这一前提。

**这一项的目的是排除「PIEZO1 只是亚群标记」这一可能，而非建立亚群差异。**

### Q6｜PIEZO1 是否与组织驻留程序共变

在跨组织图谱与 `E-MTAB-10176` 中，计算 NK 细胞内 `PIEZO1` 与下列基因的**单细胞层面相关性**：

- 驻留侧：`ITGA1`（CD49a）、`CD69`、`ITGAE`（CD103）
- 出胞侧：`KLF2`、`S1PR1`、`S1PR5`、`SELL`（CD62L）
- 对照：`KLRD1`、`NKG7`（NK 谱系基因，不应特异共变）

**报告要求**：Spearman 相关及其自助法区间；相关性须在**供者内部**计算后再汇总，不得把所有细胞合并（否则供者间差异会伪造相关）。

**同时报告 `ITGA1` 与 `ITGAE` 的可测性带**——议题一实测显示 `ITGA1` 在 8/8 层落地板，若此处同样如此，该基因不能作为驻留侧代表。

**判读预先写死**：

| 观察 | 判读 |
|---|---|
| PIEZO1 与驻留侧正相关、与出胞侧负相关，且强于对照基因 | 与「PIEZO1 参与进入组织后的状态切换」相容 |
| 无一致相关，或与对照基因相当 | 该设想在转录本层面得不到支持 |
| 驻留侧基因不可测 | 记 `UNTESTABLE`，不作推断 |

### Q7｜功能读数是否可及

这是一个**可行性核查**，不是数据分析：

- 检索 NK 细胞上 PIEZO1 的**蛋白层检测手段**是否存在：可用抗体、流式方案、报告系统。
- 检索**功能读数**：Yoda1（激动剂）响应的钙成像方案，及其在原代 NK 或 NK-92 上的既有应用。
- 报告 GsMTx4 的选择性问题——它并非 PIEZO1 特异，这一点须写明。

**理由**：既然通道活性不只取决于表达量，功能读数很可能比表达量更有意义。若表达量在转录本层面不可测，功能读数即是唯一退路。
