## §0 为什么改用 bulk

任务 P-1 已确认：`PIEZO1` 在液滴单细胞数据的 NK 中落 5% 地板带（检出率 2.62%／2.73%，26/27 与 27/27 位供者落带），三条独立路径一致。**这是深度限制，不是不表达**——HPA 分选血液 NK 的 bulk RNA-seq 给出 1.0 nTPM，标注 Detected in all；且 `PIEZO1` 的 CPM 在五个谱系间基本持平，NK 检出率低主要由每细胞 UMI 仅为髓系三分之一所致。

分选后 bulk 每样本读段数高出数个量级，`PIEZO1` 必然可测。**因此本任务改在 bulk 层面进行。**

## §0.1 本任务能回答什么、不能回答什么

**能回答**：不同状态、不同来源的 NK 之间，`PIEZO1` 及其他机械敏感通道的表达是否存在差异。

**不能回答**：这些通道是否具有功能。

**须写在每份输出开头的限制**：离子通道为催化型元件，单个通道每次开放可通过约 10⁶ 个离子，故其功能重要性与表达丰度不成比例。更重要的是，`PIEZO1` 的活性取决于质膜张力——同样的表达量，在悬浮球形细胞与被基质挤压的细胞上，通道活性可相差数个数量级，而转录组对此完全不可见。

**因此本任务的产出只能支持「值得进一步测定」，不能支持「该通道重要」。这一条不得在任何表述中被弱化。**

## §1 要找什么样的数据

**分选后的 NK bulk RNA-seq。** 不要含 NK 的单细胞数据集（P-1 已证明不可用），不要未分选的 PBMC bulk（NK 只占百分之几，信号会被稀释）。

四组对比，按预期可得性排序。**每组都要找，找不到的记 `NOT_FOUND`，不得留空。**

| 序 | 对比 | 预期可得性 | 说明 |
|---|---|---|---|
| **一** | CD56^bright 对 CD56^dim | 较高 | 免疫细胞分选图谱通常已分开测定 |
| **二** | 静息对细胞因子活化（IL-2、IL-15、IL-12+IL-18 等） | 较高 | 此类数据在 GEO 中数量最多 |
| **三** | 外周血对组织驻留（肝、蜕膜、肺等） | 较低 | 尽力检索 |
| **四** | 肿瘤浸润对外周血或癌旁 | 最低 | 分选 NK 的 bulk 罕见，可能为空 |

### 第二组的额外说明

**该组可能是最快取得阳性结果的地方，且其生物学含义清楚。** NK 活化时骨架重排、发生形变、贴壁与爬行，整个细胞的力学处境随之改变；若 `PIEZO1` 随活化状态变化，说明它参与这一过程。

### 候选数据源（逐个核实，不得预设可用）

- **DICE**（免疫细胞分选 bulk，含 NK 亚群）`[待核实]`
- **Monaco 等 2019**（29 种分选免疫细胞 bulk）`[待核实]`
- **BLUEPRINT** 表观基因组联盟的分选免疫细胞 RNA-seq `[待核实]`
- **ImmGen**（小鼠，含多种 NK 亚群与组织来源）`[待核实]`
- **Human Protein Atlas** 免疫细胞分选数据（已知含 NK，`PIEZO1` = 1.0 nTPM）
- GEO 中检索 NK 分选 bulk 的活化实验、组织驻留 NK 的分选测序

**检索规则沿用既有约定**：「没找到」记 `NOT_SEARCHED`，永不留空；无法核实者记 `[待核实]`，不进入结论。

## §2 要测的基因

不只测 `PIEZO1`。**若 `PIEZO1` 不变而其他通道变化，那同样是信息。**

**机械敏感通道面板**：`PIEZO1`、`PIEZO2`、`TRPV2`、`TRPV4`、`TRPM7`、`TRPC1`、`TRPC6`、`TMEM63A`、`TMEM63B`、`KCNK2`、`KCNK4`

**力学转导下游对照**（用于判断变化是否为整个力学装置的协同改变，而非单一通道）：`YAP1`、`WWTR1`（TAZ）、`ANKRD1`、`CTGF`／`CCN2`

**状态对照**（用于说明比较的两组确实处在不同状态）：
- 活化：`IFNG`、`GZMB`、`MKI67`
- 驻留：`ITGA1`、`CD69`、`ITGAE`
- 出胞：`KLF2`、`S1PR1`、`SELL`

**物种直系同源逐个核实**，不得假定一一对应。小鼠中 `TRPV2` 为 `Trpv2`，但面板中其余基因须逐个查证——议题一曾因假定 `XCL2` 在小鼠存在而出错。

## §3 三条硬性规则

### 3.1 只在数据集内部比较

**跨数据集不得比较绝对值。** 平台、建库方案、批次效应均不同。

先例：同为肺组织 NK，`XCL1` 在跨组织图谱中为 0.556、在 `GSE154826` 中为 0.073，相差 7.6 倍——**同一组织，跨数据集的差异即可达此量级。**

跨数据集只用于**核对方向是否一致**，不合并数值，不做联合统计。

### 3.2 每个数据集须报告的元信息

- 分选方式（流式分选的门控策略、磁珠分选的标记）
- 样本数与供者数
- 平台与建库方案
- 是否为配对设计
- 每组的测序深度

**分选方式尤其重要**：以 CD56⁺CD3⁻ 分选与以 NKp46 分选得到的群体不同，混用会引入系统差异。

### 3.3 差异的判定

- 同数据集内配对设计者，用配对检验；非配对者说明并用相应方法。
- 报告效应量（log2FC）与区间，**不只报 p 值**。
- **若某数据集内 `PIEZO1` 的表达接近该数据集的检测下限**（如 TPM < 1 或落在表达分布的最低十分位），须标注，其差异不可解读。

## §5 预先写死的判读

| 观察 | 判读 |
|---|---|
| `PIEZO1` 在某一组对比中稳定变化，且在多个独立数据集中方向一致 | 存在值得追究的变化，进入功能层面的设计 |
| `PIEZO1` 不变，但面板中其他通道变化 | 对象可能选错，须重新评估议题二的分子 |
| 全面板均无变化 | 力学感受装置在这些对比中不改变，本方向须重新提问 |
| `PIEZO1` 接近检测下限，无法判定 | 记 `UNDETERMINED`；bulk 层面亦不足，须直接进入蛋白或功能层面 |
