## 复算结果 —— 与手算的两处差异

交接语要求"用原始供者层级数据复算 §6.8 的推算"。复算脚本 `scripts/v21_recompute.py`，日志 `results/v21_recompute.log`。

### 差异一：配对在本数据集上不省方差（手算未涉及）

19 位供者同时有肿瘤与邻近肺样本，故正确分析是**配对**的。但患者内相关近零或微负：

| 基因 | 患者内 r | 配对 SE / 非配对 SE |
|---|---|---|
| CCL3 | **+0.18** | 0.92 |
| CCL4 | **−0.07** | 1.00 |
| CCL5 | **−0.05** | 1.03 |
| XCL1 | **−0.09** | 1.07 |

**同一患者的肿瘤 NK 与邻近肺 NK 的检出率彼此不预测。** 配对设计在此不带来功效收益——这一点本身值得记住：以后不能默认"配对 = 更有功效"。

### 差异二：MDPC 落在阈值的另一侧，结论方向不变但依据变实

| | 手算 | 复算（配对） |
|---|---|---|
| XCL1 差值 SE | 2.09 pp | **2.23 pp** |
| MDPC(XCL1)，1-SE 尺 | **22.3%** | **23.9%** |
| R1 观测比例降幅 | ~23% | **−23.6%**（中位数） |
| §6.7 第 3 条 | 手算叙述判"不满足"，但 **22.3% < 23%，按条文字面反而"满足"** | **23.9% > 23.6% → 明确不满足** |

**这是一处必须点出的修正**：手算的**叙述结论**（不满足 → `UNMEASURED`）与它自己的**算术**（MDPC 22.3% 小于 R1 的 23%，按 §6.7 第 3 条字面应判"满足"，即允许写 `PRESERVED`）方向相反。复算把 MDPC 抬到 23.9%，**高于**对照基准，使叙述结论与算术一致。

**结论不变，且更稳**：按真实检出尺（t₀.₉₇₅，df=18）MDPC(XCL1) = **50.3%**——XCL1 要跌掉一半以上才测得出。无论取 1-SE 尺还是 t 尺，预测 2 都是 `UNMEASURED`。

### 复算的完整数字
